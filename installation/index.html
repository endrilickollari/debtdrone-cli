Installation

DebtDrone ships as a single binary. Core local scanning needs no companion service; Trivy is required only when security scanning is enabled. Choose the installation method that best fits your workflow.

Choose a package manager, release archive, or source build; every path ends with the same local verification.

Option 2 — Pre-compiled Binaries

Section titled “Option 2 — Pre-compiled Binaries”

Pre-compiled binaries are published to the GitHub Releases page for every tagged release. Download the archive for your platform, extract it, and place the binary somewhere on your PATH.

Windows ARM64

Windows ARM64 is not currently supported in the pre-compiled release artifacts. Windows ARM64 users should build from source (see below).

Option 4 — Build from Source

Section titled “Option 4 — Build from Source”

Clone the repository and build with the standard Go toolchain:

CGO requirement

The analysis engine uses tree-sitter for multi-language syntax parsing, which requires CGO. Ensure a C compiler (gcc or clang) is present on your system before building from source.

Built-in Auto-Updater

Section titled “Built-in Auto-Updater”

Install once, stay current automatically

DebtDrone ships with a built-in self-updater. Launch the TUI and use /update to check for a release, review its notes, and apply it in place. There is no headless debtdrone update subcommand in the current release.
