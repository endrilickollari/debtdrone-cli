Run your first scan

This tutorial takes you from installation to a useful local scan. It disables the optional Trivy analyzer for the first run so the result does not depend on another executable.

One scanner pipeline powers interactive exploration, JSON output, and CI quality gates.

1. Install DebtDrone

If you already have Go 1.25.1 or later and a C compiler, install the latest CLI release:

Confirm that the binary is available:

If the command is not found, add $(go env GOPATH)/bin to your PATH or use one of the alternatives in Install the CLI.

2. Open a repository

Stdout is a JSON array of findings. This makes the command suitable for shell scripts and agents. Analyzer warnings are written to stderr so they do not corrupt the JSON document.

5. Add a quality gate

Section titled “5. Add a quality gate”

Fail the command when a high or critical finding is present:

Use this form in CI only after reviewing the repository’s current findings. Starting with a threshold that already fails can block every change rather than preventing new debt.

6. Explore interactively

Section titled “6. Explore interactively”

Launch the terminal interface from the same directory:

Enter /scan to scan the current directory, use j and k to move through findings, and press Esc to return to the dashboard. See the Interactive TUI guide for the complete workflow.
